# OpenClaw Themes

Theme families for the OpenClaw Control UI.

## Christmas

The [`christmas/`](christmas/) plugin contains five themes, each with light and dark palettes and matching backgrounds: Holly & Hearth, Silent Night, Sugarplum, Gingerbread, and Delivering the Cheer.

See the [Christmas pack README](christmas/README.md) for requirements, validation and current limitations. Original editable SVG artwork is included. No credentials, runtime dependencies, or install lifecycle scripts are included.

Future theme families can live in separate top-level folders and publish independently.

## Nautical

The [`nautical/`](nautical/) plugin contains **Chart Room**, **Captain’s Quarters**, and **Signal Flags**, each with light and dark palettes and matching scenic backgrounds. Local draft; see its README for validation and limitations.
